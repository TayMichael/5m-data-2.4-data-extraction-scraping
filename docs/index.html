Has a REST API

GitHub

Has a GraphQL API

Your internal code platform — ask for exactly the fields you need.

Competitor Site

Has no API

Pricing data only exists as HTML — time to scrape.

Why this matters

A data engineer's first job is almost always "get data from Point A to Point B." APIs are the standard interface for system-to-system exchange — knowing how to authenticate, paginate, and handle errors is a daily skill. Web scraping fills the gap when no API exists, but comes with real ethical and legal limits.

Pagination

GitHub returns 30 results per page by default. pandas has 100+ releases, so we page through with two query parameters:

?per_page=100&page=1

The newest 100 releases

?per_page=100&page=2

The next 100 (older) releases

Rule of thumb

Keep requesting the next page until the server returns an empty list — that's your signal there's nothing left to fetch.

Chapter 2

REST vs GraphQL

REST returns a fixed shape decided by the server — you often get far more fields than you need. GraphQL lets you decide the shape. Toggle below to see the same release data fetched two ways.

Anatomy of a GraphQL query

query {                                            # "query" = read operation
  repository(owner: "pandas-dev", name: "pandas") { # object to start from
    releases(first: 100) {                          # sub-field, limit 100
      totalCount                                     # scalar — total count, free
      edges {                                        # the list of items
        node {                                       # one release object
          tagName
          publishedAt
          description
        }
      }
    }
  }
}

GraphQL uses an edges → node pattern for lists, and always replies via POST to a single endpoint (/graphql) — even though it's a read.

RESTGraphQL
EndpointOne per resource (/releases, /issues…)Single endpoint (/graphql)
HTTP verbGET for readingPOST (always)
Response shapeFixed — server decidesFlexible — you decide
Over-fetchingCommonNever

Before you scrape — check

robots.txt

Visit /robots.txt to see what the site allows bots to access.

Terms of Service

Some sites explicitly prohibit scraping.

Rate limiting

Add time.sleep() between requests — don't overload the server.

Copyright

Scraped data may be copyrighted — check before redistributing.

Remember

Scraped data is fragile — a website redesign silently breaks your selectors. Treat scraping as a last resort, after checking for an API.
